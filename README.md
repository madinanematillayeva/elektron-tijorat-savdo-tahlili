# E-Commerce Sales Intelligence System

Elektron tijorat platformalari uchun savdoni tahlil qilish va bashorat qilish tizimi.

## Imkoniyatlari:
- Kunlik savdo dinamikasi va KPI ko'rsatkichlarini kuzatish
- Kategoriyalar va hududlar kesimida tahlil
- Machine Learning (Linear Regression) yordamida kelgusi 14 kunlik savdo bashorati
- Shaxsiy CSV ma'lumotlar bazasini yuklash imkoniyati
